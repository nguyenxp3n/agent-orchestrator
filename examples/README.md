# Examples: Non-Prescriptive Project Profiles

Các file trong thư mục này **không phải cấu trúc bắt buộc của framework**. Chúng chỉ minh họa cách cùng một methodology được map vào nhiều loại dự án.

- `six-agent-web-project.md`: Web Fullstack.
- `backend-microservices.md`: Microservices Backend.
- `mobile-project.md`: Mobile App.
- `cli-project.md`: CLI / developer tool.
- `ten-agent-project.md`: team lớn hơn, domain trung tính.

Khi áp dụng Agent Orchestrator, Lead phải bắt đầu từ Project Intake và Project Execution Profile của repository thực tế. Không copy migration, path, ports, commands, roles hay WP decomposition từ example nếu evidence của project không hỗ trợ chúng.
